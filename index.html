💰 SalaryScope — Salary Predictor

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A ridge regression model trained on 600 synthetic job profiles predicts annual salary (LPA) from experience, education, skills, internships, certifications and city tier. 5-fold CV: R² = 0.938, MAE = 1.22 LPA vs a 5.13 LPA mean-guess baseline.

How it works: each input is standardised with the training means and standard deviations, then multiplied by the model's learned coefficients. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model to within 0.01 LPA.

Try a sample: 2 years experience, bachelor's degree, 5 skills, 1 internship, 2 certifications, tier-1 city → about 12.81 LPA. A senior profile — 15 years, PhD, 14 skills, 5 internships, 8 certifications, metro — → about 36.17 LPA.
